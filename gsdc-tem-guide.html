Lmod 환경 모듈 사용법

소프트웨어 환경을 동적으로 로드/언로드

주요 module 명령어

명령어설명
module avail사용 가능한 모듈 목록
module list현재 로드된 모듈
module load <path>모듈 로드
module unload <path>모듈 언로드
module purge모든 모듈 제거
module spider <keyword>전체 모듈 검색
module keyword <word>설명에서 키워드 검색

사용 예시: Relion GPU 로드

# 1. 키워드로 검색 module keyword relion # 2. GPU 버전 로드 module load apps/relion/5.0.0/gpu/cuda-12.6 # 3. 의존성 자동 로드 확인 module list # → gcc/11.5.0 # → cuda/12.6 # → openmpi/5.0.3/gcc-11.5.0 # → apps/relion/5.0.0/gpu/cuda-12.6
모듈 계층 구조:
compiler → MPI → CUDA → Applications

작업 제출 & 관리

qsub / qstat / qdel 핵심 명령어

Job Script 구조

#!/bin/bash ### 큐 지정 #PBS -q gpuQ ### 자원 요청 #PBS -l select=1:ncpus=6:ngpus=2:mem=64GB ### 출력 파일 #PBS -o job.out #PBS -e job.err ### 환경변수 전달 #PBS -V module load apps/relion/5.0.0/gpu/cuda-12.6 mpirun -n 6 relion_refine_mpi ...

핵심 관리 명령어

명령어설명
qsub job.pbs배치 작업 제출
qsub -I -q cpuQ ...인터랙티브 작업
qsub -X -V -I ...X11 GUI 인터랙티브
qstat -u $USER내 작업 상태 확인
qstat -x jobID특정 작업 상태 (72시간)
qdel jobID작업 취소
qdel `qselect -u $USER`내 모든 작업 취소
작업 상태 코드: Q 대기  R 실행중  H 홀드

인터랙티브 작업

디버깅 · 테스트 · GUI 애플리케이션 실행

기본 인터랙티브 작업
# CPU 큐에서 4코어, 32GB, 1시간 인터랙티브 세션 qsub -I -q cpuQ -l select=1:ncpus=4:mem=32GB -l walltime=01:00:00 # 결과: 컴퓨팅 노드에 직접 접속 [userid@tem-cpu00-al9 ~]$
GUI(X11) 인터랙티브 작업 — Relion, CisTEM 등 GUI 실행 시
# X11 포워딩 + 환경변수 전달 포함 qsub -X -V -I -q cpuQ -l select=1:ncpus=1:mem=16GB -l walltime=01:00:00 # X11 환경 확인 [userid@tem-cpu00-al9 ~]$ echo $DISPLAY localhost:50.0 [userid@tem-cpu00-al9 ~]$ relion # GUI 실행
💡 팁: 로컬 PC에서 SSH 접속 시 -X 또는 -Y 옵션으로 X11 포워딩 활성화 필요
ssh -X userid@tem-ui-al9.sdfarm.kr
