# Requesting accounts

Before using the GSDC TEM computing cluster, send an application form to the TEM service manager by e-mail to get a user account for accessing the cluster.

!!! note "Download GSDC TEM Application Form"

    [:octicons-download-24: Dowload Application Form](https://github.com/gsdc/tem-docs/raw/master/docs/GSDC-TEM-APPFORM-2024.pdf){ .md-button}

If you already have a valid user account, you can connect to the UI (user interface) login servers to use various cluster computing/storage resources and software environments, including data analysis tools like Relion and CryoSPARC.
