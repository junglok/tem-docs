# **Welcome to GSDC TEM Users Guide**

This is the GSDC TEM Users Guide for the new AlmaLinux 9.x based TEM cluster.

For the guide covering the old ScientificLinux 7.x based system, see [Scientific Linux 7.x based GSDC TEM Users Guide](https://tem-docs.readthedocs.io/en/el7/).

## **Notice**

???+ tip "Unified technial supports to request the support for resolving techinical problems/errors using GSDC services"

    Since September 2026, we've launched GSDC DigitalHub Portal to provide users supports to handle technical problems. 
    
    __[GSDC DigitalHub Portal](https://portal.gsdc.kr)__ : __Technical Support__ -> __Contact Support__

    For technical support requests regarding issues, errors, usage guidance, or additional improvements encountered while using the GSDC TEM analysis infrastructure and environment, please use “Technical Support” -> “Contact Support” in the sidebar menu.

    When you submit a new ticket (inquiry), it will be immediately delivered to the service manager. You can check the entire processing status and details of your ticket on the GSDC Digital Hub portal.
    

???+ tip "(Deprecated) Creating tickets to request the support for resolving techinical problems/errors using GSDC services"

    Since March 2021, we've run a GSDC ticketing system to handle technical problems for users and operators, so feel free to create tickets. 
    
    `"Creating tickets"` simply means sending an e-mail to the address below. The e-mail subject prefix determines who on our team the ticket is automatically assigned to.
    
    E-mail address : __gsdc-support at kisti.re.kr__ (__[TEM]__ prefix required in the e-mail subject)
